# GPT-2-Based Retrieval Chatbot

A Python-based chatbot that retrieves relevant responses from a pre-generated GPT-2 dialogue dataset using TF-IDF vectorization and cosine similarity. The project combines text preprocessing and information retrieval techniques to match user queries with the most relevant available responses.

## Project Overview

This project implements a retrieval-based chatbot using Python and a pre-generated GPT-2 dialogue dataset from [Kaggle](https://www.kaggle.com/datasets/abhishek/gpt2-output-data/data). It processes and cleans dialogue text, converts textual data into numerical representations using TF-IDF vectorization, and applies cosine similarity to identify responses relevant to user queries.

### Key Features

- **Text Preprocessing:** Cleaned and prepared dialogue data for text analysis.
- **TF-IDF Vectorization:** Converted text into numerical feature representations.
- **Cosine Similarity:** Compared user queries with available dialogue data to retrieve relevant responses.
- **Chatbot Implementation:** Integrated the retrieval process into a Python-based conversational system.

### Technologies Used

- Python
- TF-IDF Vectorization
- Cosine Similarity
- Text Preprocessing
- GPT-2 Dialogue Dataset

### Project Objective

To develop a simple chatbot that demonstrates how natural language processing and information retrieval techniques can be used to match user queries with relevant conversational responses.
